# 踩过的坑与设计取舍

这份文档是项目里最值钱的部分 —— 全部是真金白银试出来的。如果你想自己改脚本，先读这里能省掉几天。

## 1. `page.evaluate()` 没有超时，会无限挂起

**现象**：脚本卡在某个 `frame.evaluate()` 上，日志十几分钟不动。

**原因**：当 frame 正在导航、或 iframe 只挂了一个空壳（执行上下文一直不 attach）时，`evaluate` 会一直等下去，Playwright 层面没有超时。

**解法**：用 `frame.wait_for_function(fn, timeout=..., polling=100)` 代替，它超时会抛异常。见 `scripts/pjs.py`：

```python
handle = target.wait_for_function("(a) => ({v: (() => {" + body + "})()})",
                                  arg=arg, timeout=timeout, polling=100)
return handle.json_value()["v"]
```

## 2. `polling` 默认是 `requestAnimationFrame`，窗口不可见就永远不触发

**现象**：窗口最小化 / 放到屏幕外以后，所有带 `wait_for_function` 的调用**全部超时**，页面看起来"卡死"。

**原因**：rAF 在窗口不可见时不执行，而 `wait_for_function` 默认按 rAF 轮询。

**解法**：显式 `polling=100`（毫秒定时轮询），配合浏览器启动参数 `--disable-background-timer-throttling --disable-backgrounding-occluded-windows`。

## 3. 窗口最小化后 JS 定时器被降频，页面逻辑根本不跑

**现象**：视频页不加载、`#iframe` 的 `src` 永远不被赋值、分页不翻。

**解法**：启动参数关掉节流；把窗口放在屏幕外（`--window-position=-3200,-3200`）而不是最小化；必要时用 CDP 把窗口固定回最小化/屏外（见本项目的 `pin_minimized` 思路）。

## 4. SPA 用 hash 路由：`goto` 同一个 URL 不会重新渲染

**现象**：处理完一节课回到目录，"回目录"那步执行了但页面还是旧状态，后面的 `click failed` 一片。

**原因**：`#/learn/content` 这种 hash 变化不触发整页加载，Playwright 的 `goto` 会"成功"但页面没重载。

**解法**：先 `goto("about:blank")` 再 `goto(目标 URL)`，强制重新加载。

## 5. `display(x)` 在某些执行环境里不产出 stdout

**现象**：在无图形界面的 Julia/REPL 里跑脚本，`display` 的矩阵不出来。

**解法**：改用 `println`。

## 6. 点击 `li` 不一定会勾选选项

**现象**：脚本对每道题都点了选项，日志显示"已填 30 题"，提交后却是 0 分。

**原因**：超星/慕课的选项是 `<li onclick="addChoice(this)">`，点 `li` 只是触发外层；有的页面要点 `input`，有的要点 `label`，还有的点 `label` 会**取消**选择。

**解法**：点完必须**回读** `li[aria-checked]` / `input.checked`，没勾上再换目标点；提交前统计"已勾选/总题数"，不足就别提交。

## 7. 提交后要处理确认弹窗

**现象**：点"提交"没反应，页面停在原地。

**原因**：提交走 `onclick="btnBlueSubmit()"`，会弹 `#popok` 确认框；不点它请求不会发出。

**解法**：点提交后循环等 `#popok` 并点掉；同时监听 `dialog` 事件（JS `alert` 会阻塞页面）。

## 8. 讨论区发帖的"假成功"

**现象**：脚本日志"发帖成功、页面能搜到正文"，但刷新后回复数没变、`learned` 一直是 false。

**原因**：编辑器（Quill）里的文字还在 DOM 里，所以"页面能搜到正文"是假阳性；真正的成功标志是**回复数 +1**。

**解法**：提交后 `reload`，对比"共 N 个回复"的 N 是否增加。

## 9. 平台有每日回帖上限

**现象**：连续发几十条后，发帖接口返回成功但内容不入库。

**验证方法**：拿一条**以前发成功过**的老讨论再发一次，如果同样失败，就是全局额度用完了。

**解法**：等额度重置（通常是次日零点）再发，或者手动发。

## 10. 字体混淆（超星章节测验）

**现象**：题目文本取出来是 `嘍嗁喿嗀要嗂嗃嚳些类型` 这种乱码。

**原因**：页面用了自定义字体，把常用字映射到私有字形。

**解法**：下载同款参考字体（Source Han Sans），把网页字体里每个字形的轮廓与参考字体的候选字做匹配，还原真字。见 `webquiz/fontdecode.py`。这一步的正确率取决于字体版本，建议保留人工复核环节。

## 11. 作业附件容易"交了但没传上"

**现象**：作业显示"已完成并提交"，但答题区只有文字，没有附件。

**原因**：`set_input_files` 之后没等上传完成就点了提交。

**解法**：上传后轮询答题区，确认出现附件缩略图/文件名再提交。

## 12. 别在同一个标签页上并行跑两个任务

多个脚本共用一个标签页会互相导航，出现莫名其妙的 `Navigation interrupted`。要么每个任务独立标签页，要么串行。

## 13. 平台"取最高分"是安全的

超星/慕课的章节测验多数是"多次作答取最高分"。这意味着重考不会把分数做低（但会消耗次数），可以放心重试。**提交前确认规则**：有的课是"取最后一次"，那就完全不同了。
