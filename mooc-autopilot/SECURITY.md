# 安全申明

本文件说明本项目如何处理数据、哪些文件属于敏感信息、以及使用时的安全边界。

## 一、数据流向：全部在本地

本项目**没有任何服务端**，不会把数据上传到任何第三方（除了你自己配置的大模型 API）。

| 数据 | 去向 |
|---|---|
| 课程页面内容、题目、答案 | 只在你本机的 `out/` 目录里 |
| Cookie | 只在你本机的 `cookies.txt`，仅用于注入到你自己的浏览器 |
| 大模型 API Key | 从环境变量读取，直接发给你自己配置的 API 端点 |
| 账号密码 | **本项目从不接触**——它接管的是你已经登录好的浏览器 |

如果你配置了大模型答题，题目文本会发送到该模型服务商（默认 DeepSeek）。**涉及个人隐私或不允许外发的内容，请勿开启此功能。**

## 二、敏感文件（绝对不要提交、不要截图、不要发给别人）

| 文件 | 泄露后果 |
|---|---|
| `cookies.txt` | 别人可以直接登录你的账号（学习通/慕课） |
| `config.yaml` | 含课程 URL 里的 `enc`、`cpi`、`clazzid`，可定位到你的学校、班级 |
| `answers.json` | 含你的作答内容 |
| `.env` / 环境变量里的 `DEEPSEEK_API_KEY` | 别人可以盗刷你的 API 额度 |
| `out/` 目录 | 含抓取的页面、题目、成绩 |

`config.yaml`、`cookies.txt`、`answers.json`、`out/`、`.cache/` 都已在 `.gitignore` 中排除。
**提交前务必执行 `git status` 确认没有这些文件。**

## 三、API Key 的正确用法

```bash
# Windows
set DEEPSEEK_API_KEY=sk-xxxx
# macOS / Linux
export DEEPSEEK_API_KEY=sk-xxxx
```

- 写进环境变量，**不要写进配置文件**；
- 不要把 Key 贴到聊天记录、截图、issue 里；
- 发现泄露立即去服务商后台吊销。

## 四、自动化操作的安全边界

1. **只操作你自己的账号、你自己的课程**。操作他人的账号可能违反平台规则，甚至触犯法律。
2. **控制频率**。脚本默认有 10~30 秒的随机等待；不要改成 1 秒一次，容易被风控封号。
3. **提交类操作不可逆**。章节测验一旦提交就计入次数，先 dry-run 看日志。
4. **留意平台的每日上限**。讨论区有每日发帖上限，超了会"静默失败"（接口返回成功但内容不入库）。
5. **不要用它绕过考试**。期末考试、需要人脸识别/摄像头的场景，本项目不覆盖，也不应尝试绕过。

## 五、代码层面的安全设计

- 不内置任何账号密码字段；
- 不读取浏览器密码库；
- 不写入系统目录，所有产物在项目目录内；
- 不修改页面以外的系统状态。

---

如果你发现安全问题（例如某个文件意外包含了可识别个人身份的信息），请提 issue 或直接联系维护者，不要公开贴出敏感内容。
